# @astrojs/vite-plugin-pages

A Vite plugin for Astro pages: file-based routing in `src/pages/`, the dev server, the production build, and the server request pipeline, plus the extension API (`api.astroPages`) that feature plugins build on. It requires `astro()` from `@astrojs/vite-plugin-astro`. This package is at an early stage: it currently ships the plugin API and route types used by `astro`; see [API.md](./API.md) for the contract.
